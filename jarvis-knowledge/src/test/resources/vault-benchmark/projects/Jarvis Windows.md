# Jarvis Windows

Klient Windows jest napisany w JavaFX 21 i komunikuje się z Core przez OkHttp (REST, SSE, WebSocket).

## Funkcje

### Wpis 1

Rutynowa kontrola (klient) numer 1: sprawdzono logi systemowe, obciążenie procesora, temperatury dysków oraz stan aktualizacji pakietów. Nie stwierdzono nieprawidłowości, konfiguracja usług pozostała bez zmian.
